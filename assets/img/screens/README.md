# Product tour screenshots

The screenshots in this folder appear in the "Product tour" section of the site. To change one, replace its file and keep the same name. If a file is missing, the site shows a "Screenshot coming soon" placeholder in its place.

| File | Where it appears |
|---|---|
| `web-manager-dashboard.png` | Large browser frame: cooperative manager dashboard |
| `web-disease-monitoring.png` | Large browser frame: disease outbreak map |
| `mobile-farmer-alerts.jpg` | Phone frame: farmer alerts list |
| `mobile-record-event.jpg` | Phone frame: "Select Event" screen for recording an event |

Images keep their own proportions and are not cropped.

**Only use screenshots of demo or seed data.** Make sure none show real personal details, API hostnames, tunnel URLs or keys. Check for browser hover tooltips that show URLs.
